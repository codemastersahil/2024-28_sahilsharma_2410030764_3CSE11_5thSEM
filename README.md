# ☁️ AWS Service Explorer

AWS Service Explorer is a simple and interactive web application developed using Python and Streamlit. It helps beginners explore selected AWS services and understand their features, categories, and practical business applications.

## 📌 Project Overview

AWS provides many cloud services, which can sometimes be difficult for beginners to understand and compare.

This project provides a simple interface where users can select, search, and compare AWS services in one place.

The application is designed as an educational project to provide basic information about AWS cloud services.

## 🎯 Objectives

- Provide basic information about selected AWS services.
- Help beginners understand AWS services easily.
- Display key features of each service.
- Show practical business applications.
- Allow users to search for services.
- Allow users to compare two AWS services.

## ✨ Features

- 🔍 Search AWS services
- 📋 Explore AWS service information
- ⭐ View key features
- 💼 View business applications
- ⚖️ Compare two AWS services
- 📊 View basic service statistics
- 📱 Simple and interactive web interface
- 📌 About Project section

## ☁️ AWS Services Included

The application currently includes:

1. Amazon S3
2. Amazon EC2
3. Amazon RDS
4. Amazon Aurora
5. Amazon SES
6. Amazon WorkMail
7. Amazon Pinpoint
8. AWS Generative AI
